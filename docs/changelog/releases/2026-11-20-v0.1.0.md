# v0.1.0 · 2026-11-20

提供 Windows 10 / 11 64 位安装程序，以及 Android 7.0 及以上 ARM64 设备的 APK。

## 主要功能

- 笔记仓与随手记：Markdown 即时编辑、目录管理、图片与多格式附件，主动保存。
- 待办：时间线、循环待办与无定期事项，支持历史记录和完成状态。
- 设备发现、可读设备名称与局域网配对同步。
- 结构化数据使用 SQLite；Markdown 和附件保留为普通文件。
- 统一回收站与未引用附件扫描清理。
- 软件更新检查与签名校验的前端热更新能力。

## 本次修复

- 改善移动端输入框、编辑区与软键盘之间的布局。
- 修复弹窗上移后“取消 / 确认”按钮行出现独立白条的问题。
- 退出登录前增加确认弹窗。
- 统一笔记仓与待办的滑页、标题和底部分页指示器效果。

## 下载

访问 [软件下载](/download/) 或 [GitHub Release](https://github.com/Lee7017/pleasejot/releases/tag/v0.1.0)。Release 同时提供 Windows EXE、MSI、Android APK 和 SHA-256 校验值。

Android 正式包使用独立的发行签名，不能直接覆盖之前的调试包；卸载调试包前请自行备份需要保留的数据。
